# IGOTOWATCHMOVIES 使用手册

> 版本：v1.8.1 | 更新时间：2026-06-03 | [GitHub](https://github.com/Onetucenasshole/vibecoding-workspace)

---

## 一、插件概述

IGOTOWATCHMOVIES 是一个 Chrome 浏览器扩展，用于将豆瓣电影/电视剧/动漫/图书条目**一键同步**到飞书多维表格。支持单条导入和批量同步。

### 支持同步的字段

| 分类 | 字段 |
|------|------|
| 基本信息 | 标题、链接、封面（豆瓣 + TMDB 双重保障） |
| 影视详情 | 导演、编剧、主演、类型、制片国家、语言、上映日期、片长 |
| 图书详情 | 作者、译者、出版社、出版年、ISBN、页数、定价、装帧 |
| 公共评分 | 豆瓣评分、评分人数 |
| 个人数据 | 个人评分、打分日期、短评 |
| 自动分类 | 种类（电影/电视剧/动漫） |
| 进度状态 | 已看完/想看/正在看（批量同步时从链接自动识别） |

---

## 二、安装

1. 打开 Chrome 浏览器，地址栏输入 `chrome://extensions/`
2. 开启右上角「开发者模式」
3. 点击「加载已解压的扩展程序」
4. 选择插件目录
5. 插件图标出现在浏览器工具栏

---

## 三、飞书配置

### 3.1 创建飞书应用

1. 登录 [飞书开放平台](https://open.feishu.cn/)
2. 创建企业自建应用
3. 获取 **App ID** 和 **App Secret**
4. 开通权限：`云文档 > 多维表格`（全部权限）

### 3.2 飞书多维表格字段说明

在飞书多维表格中，建议按以下类型创建字段：

| 字段名 | 建议类型 | 说明 |
|--------|---------|------|
| 豆瓣ID | 文本 | 用于去重 |
| 影视标题 | 文本 | 条目名称 |
| 导演 | 文本 | |
| 编剧 | 文本 | |
| 主演 | 文本 | |
| 类型 | 文本 | 剧情/喜剧/... |
| 制片国家 | 文本 | |
| 语言 | 文本 | |
| 上映日期 | 文本 | |
| 片长 | 文本 | |
| 条目链接 | URL | 豆瓣链接 |
| 影视封面 | 附件 | 海报图片 |
| 豆瓣评分 | 数字 | |
| 个人评分 | 数字 | |
| 打分日期 | 日期 | |
| 我的短评 | 文本 | |
| 种类 | 多选 | 选项：电影、电视剧、动漫 |
| 进度状态 | 单选 | 选项：已看完、想看、正在看 |

### 3.3 在插件中配置

1. 点击插件图标 → **设置** tab
2. 填入 App ID、App Secret
3. 粘贴「单条导入表格（影视）」飞书链接 → 单条同步写入此表
4. 粘贴「批量导入表格（影视）」飞书链接 → 批量同步写入此表
5. 链接格式：`https://my.feishu.cn/base/xxx?table=xxx`（仅支持完整格式）
6. 点击「验证连接」

## 四、单条导入

### 使用场景
打开任意豆瓣详情页，将当前条目导入飞书。

### 操作步骤
1. 打开豆瓣电影/图书详情页
2. 点击插件图标 → **同步** tab
3. 选择类型（电影/图书） → 获取信息
4. 确认信息 → 保存到飞书

### 注意事项
- 个人评分、日期、短评**必须**在已登录状态下导入

---

## 五、批量同步

### 使用场景
从豆瓣个人列表页批量导入多个条目。

### 操作步骤
1. 在浏览器中打开豆瓣个人列表页
   - 仅支持：`/people/xxx/collect`（看过）
   - `/people/xxx/wish`（想看）
   - `/people/xxx/do`（正在看）
2. 点击插件图标 → **批量** tab → 扫描 → 开始批量同步
3. 自动根据链接识别进度状态并写入飞书

### 数据来源

| 数据类型 | 来源 | 登录态 |
|---------|------|--------|
| 标题、导演、演员、类型等公开字段 | 批量 fetch 详情页 HTML | 不需要 |
| 个人评分、打分日期、短评 | 列表页 DOM 提取 | 需要登录 |
| 封面 | 豆瓣提取 + TMDB API | 不需要 |
| 进度状态 | URL 自动识别 | 不需要 |

### 注意事项
- 批量同步时**必须在登录了豆瓣的浏览器标签页中操作**
- 封面优先 TMDB API，无 Key 时使用豆瓣封面
- 批量同步不会重复导入已存在的条目（按豆瓣ID去重）
- 如已有条目但完整度较低，会自动更新补全

## 六、TMDB 封面配置

1. 前往 [TMDB 官网](https://www.themoviedb.org/) 注册账号
2. 进入 [API 设置](https://www.themoviedb.org/settings/api) 申请 API Key
3. 将 API Key 填入插件弹窗的「TMDB API Key」输入框

### 封面获取逻辑
- 单条导入：优先豆瓣封面，TMDB 作为备选
- 批量同步：豆瓣封面 + TMDB 双重保障

---

## 七、电影/电视剧/动漫自动分类

插件会根据以下规则自动判断条目种类并填入飞书「种类」多选字段：

| 判断条件 | 分类结果 |
|---------|---------|
| genres 含「电视剧」「综艺」「真人秀」 | 电视剧 |
| 片长含「集」（如 45分钟×12集） | 电视剧 |
| 信息中含「集数:」「首播:」「单集片长:」 | 电视剧 |
| 标题含「第X季」且确认有剧集 | 电视剧 |
| genres 含「动画」「动漫」 | 动漫 |
| 以上都不满足 | 电影 |

## 八、进度状态自动识别

批量同步时从链接自动识别进度状态：

| URL 路径 | 进度状态 |
|---------|---------|
| `/people/xxx/collect` | 已看完 |
| `/people/xxx/wish` | 想看 |
| `/people/xxx/do` | 正在看 |

飞书「进度状态」字段需设为**单选**类型，预设以上三个选项。

## 九、常见问题

### Q: 批量同步时个人评分/日期/短评为空？
A: 确保在**登录了豆瓣账号**的浏览器标签页中进行批量同步。个人数据从列表页 DOM 提取，需要登录态。

### Q: 封面没有获取到？
A: 确认已配置 TMDB API Key。如未配置，会使用豆瓣封面。冷门条目可能两者都搜不到。

### Q: 种类字段没有选项可选？
A: 确保飞书表格中「种类」字段已创建为**多选**类型，并预设了「电影」「电视剧」「动漫」三个选项。

### Q: 进度状态没有写入？
A: 确保在 `/people/xxx/collect|wish|do` 页面进行批量同步，其他页面（TOP250、豆列）不支持。

### Q: 飞书链接验证不通过？
A: 链接格式必须为 `https://*.feishu.cn/base/{appToken}?table={tableId}`，其他域名或格式会被拒绝。

### Q: 批量同步和单条导入写到了同一个表？
A: 设置页有两个独立的表格链接输入框，「单条导入表格」和「批量导入表格」分别写入对应表格。
